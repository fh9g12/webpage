# GitHub Actions Deployment Setup

This repository uses GitHub Actions to build and deploy the Jekyll site with jekyll-scholar support.

## Setup Instructions:

### 1. Repository Settings
1. Go to your GitHub repository → **Settings** → **Pages**
2. Under "Source", select **"GitHub Actions"**
3. Save the settings

### 2. Branch Structure
- **`source` branch**: Contains your source code (this branch)
- **`gh-pages` branch**: Contains the built site (auto-generated by GitHub Actions)

### 3. Workflow
The workflow (`.github/workflows/jekyll.yml`) will:
1. Trigger on pushes to the `source` branch
2. Install Ruby and dependencies
3. Build the Jekyll site with jekyll-scholar
4. Deploy the built site to the `gh-pages` branch
5. GitHub Pages serves the site from the `gh-pages` branch

### 4. First Deployment
1. Commit and push your changes to the `source` branch
2. Go to **Actions** tab in your GitHub repository
3. Watch the workflow run
4. Once successful, your site will be live at your GitHub Pages URL

### 5. Bibliography Features
With this setup, you can use all jekyll-scholar features:
- `{% bibliography %}` tags
- Automatic PDF and BibTeX buttons
- Abstract toggles
- Citation formatting

## Troubleshooting
- Check the Actions tab for build errors
- Ensure all files are committed to the `source` branch
- Make sure GitHub Pages is set to use "GitHub Actions" as source
